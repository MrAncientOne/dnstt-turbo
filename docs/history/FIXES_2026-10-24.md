## Behavior changes

| Defect | Fix and regression evidence |
|---|---|
| Empty unauthenticated polls allocate window-sized queues | Response scheduling only inspects existing outbound queues. Unknown poll IDs allocate no remote records. Remote maps also cap records at 1024 and aggregate channel slots at 262144; new-peer datagrams drop at capacity without evicting existing queues. Expiry releases capacity. These are queue bounds, not a claim to bound every KCP/server allocation. The original eight-ID wire probe falls from about 25 MiB to about 9 KiB in the measured run. |
| A stalled TCP receiver blocks other clients | One bounded FIFO writer per carrier: at most 64 queued messages and 1 MiB including the active write. Overflow closes that carrier. Payloads are copied before returning queue-admission success. Tests cover healthy-peer progress, buffer ownership, ordering, overflow, deadline, reader disconnect and shutdown. |
| Smaller EDNS caps produce incomplete DNS/TXT records | Reject a cap that cannot fit the listener's configured segment before admitting upstream data. Accepted responses never split a KCP segment; fallback DNS truncation removes whole records. Use `-mtu 1232 -tcp-mtu 16384` for mixed UDP/TCP listeners. A 4096-byte client still works with the 16384-byte listener; 1232/512 do not. A separately sized 1232/512 listener accepts matching clients. |
| Malformed tiny EDNS caps or oversized question sections stop error replies | Honor the RFC 6891 response floor of 512, and drop complete sections when a malformed request cannot be echoed within the response budget. The tiny-cap probe reproduced a stopped send loop before this final hardening; sizes 1, 2, 255, 511 and 512 with large question sections now produce parseable errors without stopping the shared sender. |
| Rate retuning erases admission-shaper debt | Retain serialization clocks when changing rate parameters. Both the four-second-debt test and the live queued-chunk test pass. |
| Small valid segments undersize adaptive receive flight | Use all positive observed PUSH payload sizes. The 176-byte case now reserves 352000 bytes rather than 45056; normal-size control also passes. |
| A terminal smux stream-open error leaves a dead local service | Close the unusable session so admission, local connections and the outer retry loop wake and rebuild KCP/Noise/smux. The forced write-error probe now returns retryable session loss. |
| Noise record failure leaves a desynchronized cipher usable | Detect short prefix/body writes; treat write, receive and integrity errors as terminal. Close the transport, expose a completion signal and wake the client session owner. Tests inject short/error writes and invalid ciphertext and check non-reuse, shutdown and listener release. This changes failure handling, not the cipher suite or wire protocol. |
| A peer's first smux response can disappear before OpenStream returns | A deterministic delayed-SYN-return test fails 3/3 with unmodified smux v1.5.24. A minimal local patch registers the stream before sending SYN and removes provisional state on failure. It passes 10/10 under race instrumentation. A full-suite byte-loss failure motivated this probe; no claim is made that it caused the earlier WAN authentication failures. |

The smux change is pinned through a local module replacement. See
[its provenance and patch notes](../../third_party/smux/PATCHES.md). Upstream
v1.5.57 was inspected and still registers after its SYN write; a version bump
alone would not fix the demonstrated ordering.

## Dependencies and toolchain

Updated uTLS 1.6.6 → 1.8.2, x/net 0.23.0 → 0.60.0, x/crypto 0.21.0 → 0.57.0,
x/sys 0.18.0 → 0.48.0, x/text 0.14.0 → 0.42.0 and compress 1.17.4 → 1.18.7.
CIRCL is no longer required by the resolved graph. KCP and the smux wire
version remain unchanged. The module now requires Go 1.26; the recommended
toolchain and these binaries use **Go 1.27.3** for the audited x509 fix.

Final govulncheck has no vulnerable imported-package or reachable-symbol
findings. Its remaining module-only notice is GO-2026-5932, concerning the
unmaintained `x/crypto/openpgp` package, which this project does not import.
This is a bounded database scan, not a guarantee against all vulnerabilities.

Verified pipe-based TLS tests cover TLS 1.2/1.3, HTTP/1.1 and HTTP/2, Firefox
and Chrome automatic/120 profiles, repeated requests, and rejection of an
untrusted certificate. This runtime refuses local TCP connects even with
listeners enabled; the pipe tests exercise real TLS/HTTP codecs, not kernel
TCP behavior or browser indistinguishability on a filtered network.

- All promoted audit, session, queue, integrity and TLS regressions pass.
- Eight production-stack simulation cases pass in both performance and race
  modes: **16/16**. Cases include static transfer, slow/adaptive links, fast

  not the valid 65535-cap workload used in the matrix.

  simulations omit kernel networking, SOCKS, tun2socks and the real WAN.

`/workspace/dnstt-audit/fixes-20261024/`. The older red audit fixtures remain
historical; their runner now uses the promoted package regressions on fixed
